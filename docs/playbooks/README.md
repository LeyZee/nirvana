# Playbooks

Procédures pas à pas pour les opérations qui reviennent. Une session qui fait l'une de ces opérations suit le playbook ; si le playbook est faux ou incomplet, elle le corrige dans la même PR.

| Playbook | Quand |
|---|---|
| `add-a-module.md` | Créer un nouveau module métier |
| `add-a-connector.md` | Brancher une nouvelle plateforme |
| `add-an-llm-provider.md` | Ajouter ou changer un fournisseur de modèle |
| `edit-the-persona.md` | Modifier la persona de Messalina |
| `write-an-eval.md` | Ajouter un scénario d'évaluation |
